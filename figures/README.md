# Figures from campaign results

Use `run_paper_figures.py --project PATH`, where PATH is the `code/` directory
of one completed campaign. The script reads its seven MAT result files and
generates the seven figures of the article. No historical snapshots are required.

Install `requirements.txt` first. Run `python figures/test_paper_figures.py`
for independent plotting tests with synthetic inputs. See
[the figure guide](../docs/PAPER_FIGURES.md) for filenames and interpretation.
