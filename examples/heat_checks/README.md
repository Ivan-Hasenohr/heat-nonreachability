# Scalar comparison and norm checks

Initialize INTLAB, add this directory to the MATLAB path, then run:

```matlab
run_heat_sine_checks
% Or one case:
checks = verify_heat_sine_filters('heat_min_time');
```

The cases are stated explicitly in `verify_heat_sine_filters.m`: heat_intro
(0.037 sin(pi*x), T=1.15), heat_positive (0.035 sin(pi*x), T=1), heat_min_time
(0.02 sin(pi*x), T=0.13), and the projected target P6 L_T(3/4), T=0.13.
They use zero initial state, y_t=y_xx+chi_omega*u on (0,1), zero Dirichlet
boundary values, omega=(1/5,2/5) union (4/5,1), and 0<=u<=1.
These assumptions are fixed in this independent checker. Changing an old
initializer or campaign script does not automatically change these checks.

No existing function or campaign is modified. The checker needs no FEM
initialization, saved witness, optimization or large propagation matrix.
Outputs go to `results/heat_checks/<case>.mat` and `.json`.

## Conclusions

Each of four necessary conditions has a status:

- `satisfied`: the necessary inequality is rigorously established. This does
  not imply reachability or undermine a separate negative-J certificate.
- `nonreachable`: a strict violation is rigorously established, proving
  non-reachability under the stated model assumptions.
- `inconclusive`: the enclosure does not decide the inequality. This is
  not evidence of a violation; increase subdivisions for comparison checks.

`certified_nonreachability` is true only if at least one obstruction is
certified. Numerical/invalid-input errors raise errors rather than proving
anything. MAT/JSON files include all statuses, norm bounds and comparison
gaps. For comparison, `violation_point` is a point inside a cell where the
gap has a strictly negative upper bound. Boundary values themselves are
zero; gaps are evaluated after division by sin(pi*x), including its limits.

## Comparison proof

Positivity of the scalar Dirichlet heat semigroup and 0<=u<=1 imply
0<=y(T,x)<=v(T,x), where v is generated by the constant maximal control.
Write v(T)=w-S(T)w, with -w''=chi_omega. The stationary solution is exactly

```
0 <= x <= 1/5:    w = 4*x/25
1/5 <= x <= 2/5:  w = 4*x/25 - (x-1/5)^2/2
2/5 <= x <= 4/5:  w = 3/50 - x/25
4/5 <= x <= 1:    w = (1-x)*(x/2-13/50).
```

The first twelve sine coefficients of S(T)w are computed by INTLAB.
Since |w_k|<=8/(pi*k)^3 and |sin(k*pi*x)|<=k*sin(pi*x), its omitted tail,
after division by sin(pi*x), is bounded by

```
8*exp(-pi^2*(N+1)^2*T)/(pi^3*N),  N=12.
```

This follows by replacing the exponent by its first omitted value and using
sum_{k>N}1/k^2<=1/N. Finite sine sums divided by sin(pi*x) are evaluated
through the recurrence for Chebyshev U polynomials on interval cells.
There are 400 cells per stationary polynomial piece by default. This is
an enclosure on every point of each cell, not a test only at sample points.
At x=0 and x=1, factored formulas use x/sin(pi*x), whose limit is 1/pi
and which is increasing on [0,1/5]. Thus the full interval is covered.

## Norm proof

Let M=sqrt(|omega|)=sqrt(2/5). L2 semigroup contraction gives

```
||y(T)|| <= M*(1-exp(-pi^2*T))/pi^2.
```

For the H1 seminorm, Cauchy-Schwarz in each orthonormal sine mode gives
lambda_k*|y_k(T)|^2 <= (1-exp(-2*lambda_k*T))/2 * integral_0^T |f_k(s)|^2 ds.
Summing gives ||y_x(T)||<=M*sqrt(T/2).
Also ||(-Delta)^(1/2)S(t)||<=sup_{lambda>=pi^2} sqrt(lambda)*exp(-lambda*t).
Integration over (0,infinity), split at 1/(2*pi^2), gives the uniform
bound 2*M/(pi*sqrt(e)). The smaller of the two bounds is used.
Target norms follow from sine orthogonality and are enclosed by INTLAB.
